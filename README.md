# Atmosphere项目

## 中文版本


### 项目概述

针对民间自发漂流活动及野外游泳区域（野泳池）缺乏有效监管、险情响应滞后等安全问题，我们计划推出一套低成本、高实效的智能监测预警解决方案。

**核心目标**：解决野外溪流等场景的气象/洪水/内涝安全问题, 同时保护周围平民百姓安全。

### 方案详情

#### 1. 硬件：精准监测，成本可控

- **成本控制**：单点硬件设备综合成本严格控制在 **300-400 元** 区间，确保项目具备高性价比与可复制性。
- **核心功能**：设备集成高灵敏度水流速度传感器，实现实时动态监测，并内置历史流速趋势分析模块。通过对比实时数据与过去时间段的水流变化规律，系统可智能过滤自然波动带来的误报，精准判定危险临界值，为后续警报提供确切的数据支撑。

#### 2. 软件：联动响应，信息可视

- **系统定位**：软件作为硬件的配套辅助管理端，负责数据处理与指令下发。
- **警报机制**：当监测数据触发危险阈值，系统将立即推送紧急预警信号至工作人员终端，确保险情在第一时间得到人工确认与干预。

#### 3. 现场部署方案

软件显示界面将落地安装在野泳池及漂流起终点旁的电子显示屏（电视）周边。这种"现场投屏"设计，确保岸边巡视人员及救生员能够直观、实时获取警报状态，极大缩短从"发现险情"到"实施救援"的反应链路，可以让人们危险来临前尽快撤离，保卫安全。

### Solution Details

#### 1. Hardware: Precision Monitoring, Controllable Cost

- **Cost Control**: The comprehensive cost of a single hardware device is strictly controlled within the range of **300-400 yuan**, ensuring the project has high cost-effectiveness and replicability.
- **Core Functions**: The device integrates a high-sensitivity water flow velocity sensor to achieve real-time dynamic monitoring, and includes a built-in historical flow rate trend analysis module. By comparing real-time data with water flow change patterns from past time periods, the system can intelligently filter false alarms caused by natural fluctuations, accurately determine dangerous threshold values, and provide definite data support for subsequent alerts.

#### 2. Software: Linked Response, Information Visualization

- **System Positioning**: Software serves as the supporting management terminal for hardware, responsible for data processing and command distribution.
- **Alert Mechanism**: When monitoring data triggers dangerous thresholds, the system will immediately push emergency warning signals to staff terminals, ensuring that dangerous situations are confirmed and intervened at the first moment.

#### 3. On-Site Deployment Plan

The software display interface will be installed on electronic display screens (TVs) near wild swimming pools and drift starting/ending points. This "on-site casting" design ensures that shore patrol personnel and lifeguards can intuitively and real-time obtain alert status, greatly shortening the response chain from "discovering danger" to "implementing rescue", allowing people to evacuate as soon as possible before danger arrives and ensuring safety.
