# 01_WindSensor 风速传感器

## 功能简介

使用**三杯式风速计**（0~5V 模拟电压输出）实时测量风速，通过串口监视器显示风速数值（km/h 和 m/s），并在**风速超过 10 km/h 时触发报警**。

## 硬件接线

| 传感器引脚 | 接到 Arduino UNO |
| ---------- | ---------------- |
| 红线       | A0（模拟输入）   |
| 黑线       | GND              |
| 报警指示   | 引脚 13（默认使用板载 LED，可外接有源蜂鸣器实现声音报警） |

## 工作原理

1. 读取模拟引脚 A0 的 ADC 原始值（0~1023）
2. 换算成电压：`电压 V = ADC值 × 5.0 / 1024`
3. 按官方标准公式换算风速：`风速(km/h) = 100 × 电压`
   - 例：读到 1V → 100 km/h；0.5V → 50 km/h
4. 同时转换为 m/s 单位（km/h ÷ 3.6）方便对比

## 报警功能

- **触发条件**：风速 > 10 km/h
- **报警方式**：
  - 板载 LED（引脚 13）快速闪烁（亮 0.2s / 灭 0.2s）
  - 串口打印警告信息：`!!! 警告：风速超过 10 km/h，请注意防范强风 !!!`
- **风速正常时**：LED 关闭，串口每 0.5 秒刷新一次数据

## 使用方法

1. 用 Arduino IDE 打开 `01_WindSensor.ino`，选择正确的板卡（Arduino UNO）和端口
2. 烧录代码到开发板
3. 打开串口监视器（Ctrl+Shift+M），波特率选择 **9600**
4. 对着传感器吹气可看到风速数值明显变大；风速超过 10 km/h 时触发报警

## 串口输出示例

```
ADC=512  电压=2.50V  风速=250.0 km/h (69.4 m/s)
!!! 警告：风速超过 10 km/h，请注意防范强风 !!!
```
